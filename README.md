# 🔢 JavaScript Counter App

A simple counter application built using JavaScript. Users can increase, decrease, and reset the number with button clicks. The counter does not go below 1.

---

## 🚀 Live Demo
https://muhammadmoiz-stack.github.io/JavaScript-counter-App/

---

## 📌 Features
- Increase counter value  
- Decrease counter value (stops at 1)  
- Reset counter to 0  
- Simple and clean user interface  

---

## 🛠️ Technologies Used
- HTML  
- CSS  
- JavaScript  

---

## 🎯 Purpose
This project is made to practice:
- DOM manipulation  
- Event handling  
- Basic JavaScript logic  

---

## 📂 How to Use
1. Download or clone the repository  
2. Open `index.html` in your browser  
3. Use buttons to control the counter
